# 🔥 פדרו - מאמן אישי

אפליקציית מובייל (דפדפן) למאמן אישי לאימוני כושר.
המאמן: פדרו - דמות קומיקס תומכת ומצחיקה עם נגיעות ספרדיות.

## איך מריצים?
פותחים את `index.html` בדפדפן, או מעלים לאתר חינמי כמו GitHub Pages.

## מבנה התיקיות
- `index.html` - דף הבית
- `styles.css` - עיצוב (אש ולבה 🔥)
- `app.js` - הלוגיקה
- `assets/` - תמונות וצלילים
